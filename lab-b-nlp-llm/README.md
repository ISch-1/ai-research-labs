# Lab B — NLP & LLM Research

Natural-language processing from sparse features to retrieval-augmented generation, with
rigorous evaluation of LLM-based systems.

| Module | Topic | Status |
|---|---|---|
| B1 | TF-IDF vs. static vs. sentence embeddings | ⚪ |
| B2 | Text classification: linear → fine-tuned BERT → zero/few-shot LLM, learning curves | ⚪ |
| B3 | Semantic search & RAG: BM25 vs. dense vs. hybrid, re-ranking, Recall@k / MRR / nDCG | ⚪ |
| B4 | LLM answer evaluation: reference metrics, LLM-as-a-judge (validated vs. human labels), RAG faithfulness | ⚪ |
| B5 | Cost / latency / quality trade-offs: local (Ollama) vs. API models, Pareto frontier | ⚪ |

Starts in Phase 2. Same layout as Lab A (`configs/`, `src/lab_b/`, `notebooks/`, `reports/`).
API keys go in `.env` (see `.env.example`), never in the repo.
