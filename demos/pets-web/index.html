    Reading the map

    The map is Grad-CAM on the network's last 5×5 feature map. Because the head is global average pooling plus one linear layer, it equals the classic class-activation map and needs no gradients — that is what lets it run in the browser.

    It shows where the evidence is, coarsely. In the lab's deletion test, Grad-CAM on the network's last block (also 5×5) did not single out the pixels the model relies on better than chance, while Integrated Gradients did; the Python version of this demo offers both.

    Limitations

    • It only knows 37 pure breeds: mixed breeds, other animals and objects still get a breed name. Below 50% it says it is unsure.
    • Look-alike breeds are its main errors: birman ↔ ragdoll, American pit bull ↔ Staffordshire bull terrier.
    • Accuracy roughly halves on very noisy or blurred photos.
    • Not for decisions about real animals — see the model card.
