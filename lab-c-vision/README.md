# Lab C — Computer Vision Research

Image classification from first principles to transfer learning, with error analysis and
visual interpretability.

| Module | Topic | Status |
|---|---|---|
| C1 | Perceptron and MLP implemented from scratch in NumPy (with gradient check), then PyTorch | ⚪ |
| C2 | CNNs from scratch vs. transfer learning (ResNet, EfficientNet, MobileNet, ViT) | ⚪ |
| C3 | Data augmentation ablation and low-data regimes | ⚪ |
| C4 | Confusion matrices, most-confident errors, calibration, robustness to corruptions | ⚪ |
| C5 | Grad-CAM, saliency, Integrated Gradients; shortcut-learning case study | ⚪ |

Starts in Phase 3. Heavy training runs have a Colab/Kaggle entry notebook; everything else
runs on CPU with small subsets.
